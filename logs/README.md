# logs/

Campaign notes. One file per investigation or rewrite push.

## Convention

- Filename: `YYYY-MM-DD-slug.md` (e.g. `2026-04-23-baseline-benchmark.md`).
- Top of file: one-line goal, status (`open` / `landed` / `abandoned`), links
  to relevant commits/PRs.
- Body: what we tried, numbers we measured, what we learned, what's next.
  Prose over bullet-points when it matters. Include dead ends — they're the
  point of keeping logs.

Not a substitute for code comments, commit messages, or [ROADMAP.md](../ROADMAP.md).
